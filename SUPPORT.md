# Support

Use the channel that matches the request:

- API and SDK questions: open a discussion or issue in the relevant public repository.
- Sandbox and institutional integration: [request access](https://heyrafiki.space/waitlist).
- Security vulnerabilities: follow [`SECURITY.md`](./SECURITY.md).
- Personal Care support: use the Help surface inside the Heyrafiki Platform.

Public issues must use fictitious examples and must never contain personal,
clinical, authentication or payment data.

# Heyrafiki

Heyrafiki is the infrastructure layer for Mental Healthcare, starting in Kenya and built for the world.

We connect People, Practitioners, Insurers and Organizations through one private system for Care, Conversations, Benefits and Payments.

Our open-source boundary covers client SDKs, healthcare-standard adapters, protocol implementations, API contracts, developer documentation, and scoring for published screening instruments. Safety thresholds, anti-fraud logic, Practitioner verification pipelines, and contract-bound payer integrations remain private.

Learn more at [heyrafiki.space](https://heyrafiki.space).
